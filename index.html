    Sync between devices

    Your decks are always saved automatically on the device you're using. Turn on sync to keep them the same on your phone and PC. They're stored as a private gist in your own GitHub account.

    1. Open GitHub's token page. The name, "no expiration" and the Gists: Read and write permission are filled in for you.
    2. Scroll down and click Generate token, then copy the code that starts with github_pat_. GitHub only shows it once.
    3. Paste it here and click Connect. Do this on each device (a new token each time is fine).

    The token stays in this browser. It can only read and change your gists, not your repositories. Don't paste it anywhere else or send it to anyone, including Claude.
